# Contributing to Commoner

Commoner is free, open source (AGPL-3.0), and has no ads, accounts or tracking. Small fixes are as welcome as big ones.

- **Report a bug or idea:** open an issue at https://github.com/letsimplfyi/commoner/issues. The category link and your phone
  and browser are plenty.
- **Send a patch:** fork, change, open a pull request. Keep changes focused and run the tests.
- **Rules:** use the brand (see DESIGN.md), no new dependencies, no build step, no third-party requests beyond Commons.

```sh
nix develop --command npm test
```
